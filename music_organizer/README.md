# Music Organizer: כלים בסיסיים לארגון ספריית המוזיקה

`Music Organizer` הוא אוסף של סקריפטים פשוטים המופעלים משורת הפקודה ומסייעים בפעולות תחזוקה וארגון בסיסיות של ספריית המוזיקה שלך.

## 🌟 תכונות עיקריות

*   **מחיקת תיקיות ריקות (`organizer.py`):** סורק עץ תיקיות ומוחק תיקיות שאינן מכילות קבצים.
*   **תיקון ג'יבריש בקבצי מוזיקה (`organizer.py`):** מזהה ומתקן בעיות קידוד (ג'יבריש) בתגי מטא-דאטה של קבצי MP3 (כותרת, אמן, אלבום וכו').
*   **בדיקת תמונות אלבום חסרות (`organizer.py`):** מזהה קבצי מוזיקה שאין להם תמונת אלבום מוטמעת.
*   **תיקון שמות "Track X" (`organizer.py`):** מחליף שמות קבצים או כותרות שירים המכילים "Track" במונח עברי מקביל ("רצועה").
*   **מיזוג תיקיות אמן (`scripts/folder_merger.py`):**
    *   ממזג תיקיות אמן בעלות שמות דומים (לדוגמה, "האמן X" ו-"אמן X").
    *   יכול להשתמש בקובץ CSV למיפוי ידני של שמות למיזוג.
    *   משתמש ב-`scripts/identify_similarities.py` לזיהוי דמיון בין שמות.

## ⚙️ דרישות והתקנה

1.  **Python:** מומלץ Python 3.9 ומעלה.
2.  **ספריות Python:** התקן את הדרישות מקובץ `requirements.txt` שבספרייה זו:
    ```bash
    pip install -r requirements.txt
    ```
    הספריות העיקריות הן: `mutagen`, `eyed3`, `jibrish_to_hebrew`.

## 🚀 שימוש

כל הסקריפטים מופעלים משורת הפקודה.

### 1. `organizer.py` - כלי ארגון ראשי

סקריפט זה מציע מספר פעולות לבחירה.

**הפעלה:**

```bash
python organizer.py
```

לאחר ההרצה, תתבקש להזין את נתיב תיקיית השורש לטיפול, ולאחר מכן לבחור את הפעולה הרצויה מהתפריט:

```
Add path folder
>>> נתיב/לתיקיית/המוזיקה/שלך

Choose action:
    [1] delete_empty_folders = Deleting empty folders from the folder tree
    [2] fix_jibrish_files = Fix wrong encoding in the music files
    [3] check_albumart = Checking files that do not contain album art
    [4] fix_track_names = Fix "Track X" names (Hebrew)
>>> מספר_פעולה
```

### 2. `scripts/folder_merger.py` - מיזוג תיקיות אמן

סקריפט זה ממזג תיקיות אמן בתוך תיקיית אב נתונה.

**הפעלה:**

```bash
python scripts/folder_merger.py
```

הסקריפט כפי שהוא כתוב כרגע מצפה לנתיבים קבועים בקוד (`dir_path` ו-`file_path` בתוך פונקציית `main`). יהיה עליך לשנות נתיבים אלו בקוד כדי להתאימם למערכת שלך, או לשנות את הסקריפט כך שיקבל נתיבים כארגומנטים משורת הפקודה.

*   `dir_path`: הנתיב לתיקייה המכילה את תיקיות האמנים שברצונך למזג.
*   `file_path`: נתיב לקובץ CSV אופציונלי המכיל מיפויים למיזוג (כל שורה: `source_name,target_name`).

הסקריפט יסרוק תחילה דמיון בין שמות תיקיות וישאל אותך אם למזג. לאחר מכן, הוא יבצע מיזוגים על פי קובץ ה-CSV.

### 3. `scripts/identify_similarities.py` - זיהוי דמיון טקסט

זהו סקריפט עזר המשמש את `folder_merger.py`. ניתן להריץ אותו גם בנפרד כדי לבדוק דמיון בין שמות קבצים/תיקיות בתיקייה הנוכחית.

**הפעלה (לדוגמה, מתוך תיקייה עם קבצים לבדיקה):**

```bash
python scripts/identify_similarities.py
```

*   חלק מהסקריפטים (כמו `folder_merger.py`) עשויים לדרוש התאמה של נתיבים בקוד המקור.
