# Album Deduplicator: זיהוי וניהול אלבומים כפולים

`Album Deduplicator` הוא כלי מקיף שנועד לנתח ספריות מוזיקה גדולות, לזהות אלבומי מוזיקה כפולים או דומים מאוד, ולהציע פעולות לניהולם. הוא משלב טכניקות השוואה מגוונות, ניתוח איכות, ובאופן אופציונלי, יכולות של למידת מכונה ו-Gemini API לשיפור הדיוק.

## 🌟 תכונות עיקריות

*   **סריקה עמוקה:** סורק תיקיות שורש באופן רקורסיבי ומזהה תיקיות אלבומים פוטנציאליות.
*   **חילוץ מטא-דאטה:** מעבד קבצי מוזיקה (MP3, FLAC, וכו') ומחלץ מטא-דאטה מקיף (כותרת, אמן, אלבום, משך, ביטרייט, האם יש מילים, האם lossless, ועוד).
*   **השוואה רב-מימדית:** משווה בין זוגות אלבומים על בסיס:
    *   **האשים של קבצים:** זיהוי זהות מוחלטת של קבצים (ניתן לכיבוי לביצועים מהירים יותר).
    *   **גודל קבצים.**
    *   **שמות קבצים וכותרות שירים.**
    *   **שמות אלבומים ואמנים.**
    *   **שם תיקיית האלבום.**
    *   **האש של תמונת האלבום (חיצונית או מוטמעת).**
    *   **משך השירים.**
    *   **קבצים נוספים בתיקייה (למשל, קבצי טקסט, log).**
    *   **מטא-דאטה נוסף (תגובות, מלחין, וכו').**
*   **ציון דמיון משוקלל:** מחשב ציון דמיון כולל לכל זוג אלבומים בהתבסס על משקולות הניתנות להתאמה אישית.
*   **ניתוח איכות:** מעריך את "האיכות" של כל אלבום על בסיס פרמטרים כמו שלמות מטא-דאטה, עברית בתגים, נוכחות תמונת אלבום, ביטרייט ממוצע, עקביות שם אמן/אלבום, פורמט lossless, ונוכחות מילים.
*   **שילוב למידת מכונה (אופציונלי):** משתמש במודל LightGBM מאומן מראש (ראה ספריית `similarity_model`) כדי לשפר את ציון הדמיון.
*   **שילוב Gemini API (אופציונלי):** משתמש ב-Gemini API של גוגל לניתוח סמנטי של זוגות אלבומים וקבלת חוות דעת נוספת על דמיון.
*   **ממשקים:**
    *   **שורת פקודה (CLI):** הפעלה גמישה עם מגוון פרמטרים (`main.py`).
    *   **ממשק משתמש גרפי (Web UI):** ממשק אינטראקטיבי מבוסס Streamlit להגדרה, סריקה, צפייה בתוצאות וביצוע פעולות (`app.py`).
*   **פעולות:**
    *   **מיזוג מטא-דאטה ותמונות אלבום:** בין אלבומים דומים מאוד, מעתיק מידע חסר מהאלבום הפחות איכותי אל האיכותי יותר.
    *   **מחיקה חכמה:** זיהוי והצעה למחיקה של אלבומים פחות איכותיים מתוך קבוצות דומות, עם העדפה לתיקיית שורש מוגדרת.
*   **מטמון (Caching):** שומר תוצאות סריקה והשוואה כדי להאיץ ריצות עתידיות.

## ⚙️ דרישות והתקנה

1.  **Python:** מומלץ Python 3.10 ומעלה.
2.  **ספריות Python:**
    *   התקן את הדרישות מקובץ `requirements.txt` שבספרייה זו:
        ```bash
        pip install -r requirements.txt
        ```
    *   **עבור תמיכה ב-Gemini API (אופציונלי):**
        ```bash
        pip install google-generativeai Pillow requests
        ```
    *   **עבור ממשק Streamlit:**
        ```bash
        pip install streamlit
        ```
3.  **מפתח Gemini API (אופציונלי):**
    *   אם ברצונך להשתמש בניתוח Gemini, הגדר משתנה סביבה בשם `GEMINI_API_KEY` עם מפתח ה-API שלך.
4.  **מודל למידת מכונה (אופציונלי):**
    *   כדי להשתמש בשיפור הדמיון מבוסס ML, ודא שהקובץ `lgbm_regressor_model.joblib` (שנוצר על ידי ספריית `similarity_model`) נמצא בתיקייה `album_deduplicator/data/`. אם הוא לא שם, העתק אותו מ-`similarity_model/models/`.

## 🚀 שימוש

### 1. ממשק שורת הפקודה (CLI - `main.py`)

ניתן להריץ את הכלי דרך שורת הפקודה עם מגוון אפשרויות.

**דוגמת שימוש בסיסית:**

```bash
python main.py "נתיב/לתיקיית/מוזיקה1" "נתיב/אחר/למוזיקה2"
```

**אפשרויות עיקריות:**

*   `folders` (חובה): נתיב אחד או יותר לתיקיות שורש לסריקה.
*   `-l, --log-level`: רמת לוג (DEBUG, INFO, WARNING, ERROR). ברירת מחדל: INFO.
*   `-p, --preferred-root`: נתיב לתיקיית שורש שתועדף לשמירה במקרה של כפילות.
*   `-b, --bitrate`: ביטרייט מועדף לאיכות ("128" או "high"). ברירת מחדל: "128".
*   `-d, --disable-hash`: מבטל חישוב האשים של קבצים (מהיר יותר, פחות מדויק).
*   `-r, --force-rescan`: מאלץ סריקה מחדש של מטא-דאטה ומתעלם ממטמון נתוני המוזיקה.
*   `-c, --clear-comparison-cache`: מנקה מטמון תוצאות השוואה ו-Gemini לפני הרצה.
*   `-m, --ml-scoring`: מפעיל ניקוד דמיון עם מודל ML מקומי.
*   `-g, --gemini-analysis`: מפעיל ניתוח עם Gemini API.
*   `-gr, --gemini-range`: טווח דמיון (למשל, "40-90") לשליחת זוגות ל-Gemini.

**דוגמה מורכבת:**

```bash
python main.py "/mnt/music_collection" "/media/external_hd/more_music" -p "/mnt/music_collection" -l DEBUG -m -g --gemini-range "50-85"
```

### 2. ממשק משתמש חדש (React + FastAPI)

בנוסף ל-Streamlit, נוספו ממשק קדמי חדש מבוסס React וממשק API ב-FastAPI המאפשרים אינטגרציה, קאשינג וזרימת עבודה מרובת שלבים.

**הפעלה מהירה:**

1. **Backend (FastAPI):**
   ```bash
   cd album_deduplicator
   pip install -r requirements.txt
   uvicorn api:app --reload --host 0.0.0.0 --port 8000
   ```
   נקודות קצה זמינות תחת `/api`, כולל `/api/scan` (הפעלה וסריקה), `/api/scan/{job_id}` (סטטוס התקדמות), `/api/scan/{job_id}/results` (תוצאות), `/api/features` (זמינות Gemini/ML) ו-`/api/actions` (הרצת פעולות מיזוג).

2. **Frontend (React + Material UI):**
   ```bash
   cd album_deduplicator/ui
   npm install
   npm run dev
   ```
   כברירת מחדל השרת יעבוד על `http://localhost:5173` ויתחבר ל-API בנתיב `/api`. ניתן לבנות גרסת הפקה עם `npm run build`.

**זרימת עבודה בממשק החדש:**

1. **Configuration:** בחירת תיקיות, העדפות hashing/ML/Gemini והגדרת bitrate מועדף.
2. **Results exploration:** הצגת זוגות דומים עם מסנני דמיון, תצוגת איכות ופרטי Gemini (אם זמינים).
3. **Action review:** בחירת זוגות למיזוג ואישור פעולה מול ה-API.

### 3. ממשק משתמש גרפי קלאסי (Streamlit - `app.py`)

ממשק Streamlit המקורי עדיין זמין להפעלה נוחה.

**הפעלה:**
ודא שאתה נמצא בספריית `album_deduplicator` בטרמינל.

```bash
streamlit run app.py
```

לאחר ההרצה, פתח דפדפן אינטרנט ועבור לכתובת שתוצג בטרמינל (בדרך כלל `http://localhost:8501`).

**שלבי הממשק:**

1.  **שלב 1: הגדרות וסריקה:** הזנת נתיבי תיקיות, בחירת תיקיית שורש מועדפת, והגדרת אפשרויות סריקה וניתוח (כולל Gemini, ML, וכו') דרך סרגל הצד.
2.  **שלב 2: הצגת תוצאות ובחירת פעולות:**
    *   סינון תוצאות לפי רמת דמיון.
    *   הצגת קבוצות דמיון והערכת איכות של כל אלבום בקבוצה.
    *   בחירה ידנית של פעולות מחיקה לכל זוג (איזו תיקייה לשמור ואיזו למחוק).
    *   אפשרות להרחיב כל זוג כדי לראות פרטי השוואה מפורטים ורשימת שירים משולבת.
3.  **שלב 3: ביצוע פעולות:** אישור סופי והעברת התיקיות שנבחרו למחיקה אל סל המחזור.

## 🛠️ תצורה (Configuration)

*   **קובץ הגדרות ראשי:** `music_dup_lib/config.py` מכיל הגדרות רבות שניתן להתאים, כגון:
    *   נתיבים לקבצי מטמון.
    *   סיומות קבצים מותרות ורשימת קבצים להתעלמות.
    *   משקולות לחישוב דמיון ואיכות.
    *   הגדרות הקשורות ל-Gemini.
*   **נורמליזציית אמנים:** הקובץ `album_deduplicator/data/singer-list.csv` (אם קיים) משמש לנורמליזציה של שמות אמנים (למשל, מיפוי "אמן X" ל-"האמן X").

## 💾 קבצי נתונים ומטמון

הכלי משתמש בתיקיית `album_deduplicator/data/` לאחסון:

*   `music_data.json`: מטמון של המטא-דאטה שנאסף על כל תיקיות האלבומים.
*   `comparison_results_cache.json`: מטמון של תוצאות ההשוואה בין זוגות אלבומים, כולל תוצאות Gemini.
*   `lgbm_regressor_model.joblib`: מודל ה-ML המאומן (אם הועתק מ-`similarity_model`).
*   `singer-list.csv`: קובץ מיפוי אמנים (אם בשימוש).
